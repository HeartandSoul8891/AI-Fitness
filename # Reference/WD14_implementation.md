💡 Important Notes for this WD14 Implementation:
Model Format: WD14 models require two files to work: an .onnx file (the neural network) and a selected_tags.csv file (the dictionary mapping outputs to text).
How to use: Create a folder inside your models/wd14 directory (e.g., models/wd14/wd-vit-tagger-v3/), and place both the .onnx and .csv files inside it. The app will automatically detect it.
